# Будем знакомы

Публичный лендинг взрослого клуба живого общения «Будем знакомы».

Production: https://budem-znakomy.vercel.app

## Принцип

На сайте нет формы регистрации, оплаты и собственной базы персональных данных. Гость выбирает событие, нажимает «Принять участие» и переходит в мессенджер с подготовленным сообщением организатору.

Telegram уже подключён к `@kava_studia`.

MAX технически подготовлен. После получения точной публичной ссылки на профиль/чат нужно заполнить в `app.js`:

```js
const MAX_CONTACT_URL = 'https://max.ru/...';
```

После этого кнопка MAX появляется автоматически. При переходе сайт сначала копирует подготовленный текст в буфер, затем открывает MAX.

## Визуальный стандарт

- основной акцент - зелёный и золотой из официального логотипа БЗ;
- официальный логотип используется в шапке, hero-блоке, информационном блоке и футере;
- афиши и фотографии не режутся под фиксированные карточки, а показываются в исходных пропорциях;
- типографика - крупная строгая editorial-подача в логике KVMC, но без копирования бренда KAVA MC;
- красный не является обязательным фирменным цветом сайта.

## Мероприятия

Будущие события добавляются в массив `upcomingEvents` в `app.js` только после подтверждения фактов.

Архив прошедших встреч находится в `archiveEvents`.

Для будущего события используются поля:

```js
{
  title: 'Название',
  date: '27.08.2026',
  time: '20:20',
  poster: '/assets/poster-name.webp',
  description: 'Короткое описание',
  venue: 'Площадка',
  address: 'Адрес'
}
```

Стоимость в карточках зафиксирована: 600 ₽ с картой клуба БЗ / 1000 ₽ без карты.

## Деплой

Репозиторий подключён к Vercel. Любой push в `main` автоматически публикует новую production-версию.
