# Будем знакомы

Публичный лендинг взрослого клуба живого общения «Будем знакомы».

Архитектура специально сделана без формы и без собственной базы заявок: сайт не просит имя, телефон, почту и не принимает оплату. Кнопка «Принять участие» открывает Telegram с готовым текстом сообщения по выбранному мероприятию.

## Обновление мероприятий

Данные лежат в `app.js` в массиве `upcomingEvents` и `archiveEvents`. Афиши — в `assets/`.

## Деплой

Репозиторий подключён к Vercel. Пуш в `main` публикует новую версию автоматически.
